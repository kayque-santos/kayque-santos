### 🤖 Chatbot RAG Multimodal

> Atendimento ao cliente automatizado com **texto, áudio e PDF**.
> Arquitetura orquestrada em **n8n** com **Gemini** como LLM e
> **Supabase pgvector** para recuperação semântica contextual.

```mermaid
flowchart LR
    A([👤 Cliente]) --> B[/WhatsApp · Web/]
    B --> C{n8n Orchestrator}
    C --> D[Speech-to-Text]
    C --> E[PDF Parser]
    C --> F[Text Pipeline]
    D --> G[(Supabase pgvector)]
    E --> G
    F --> G
    G --> H[Gemini LLM]
    H --> I([📨 Resposta])
    style C fill:#2563EB,stroke:#1e40af,color:#fff
    style G fill:#3ECF8E,stroke:#10b981,color:#fff
    style H fill:#8E75B2,stroke:#7c3aed,color:#fff
```

`Gemini` `n8n` `Supabase` `pgvector` `Python`

### 📈 Observabilidade de Dados

> para monitoramento em tempo real de pipelines de ETL e
> qualidade de chatbot RAG em produção.

```mermaid
flowchart LR
    A[Pipelines ETL] --> B[(PostgreSQL)]
    C[Chatbot RAG] --> B
    D[BigQuery] --> E[Grafana]
    B --> E
    E --> F([📊 Alertas em tempo real])
    E --> G([📈 Métricas de qualidade])
    style E fill:#F46800,stroke:#c2410c,color:#fff
    style B fill:#4169E1,stroke:#1e40af,color:#fff
    style D fill:#669DF6,stroke:#2563eb,color:#fff
```

`Grafana` `PostgreSQL` `BigQuery` `SQL`
